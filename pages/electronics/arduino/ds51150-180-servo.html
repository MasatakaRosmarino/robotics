DS51150-180 servo experiment

tools

servo motor specs

  • Operating Voltage: 10V, 12V, 12.6V; Dead brand: 3μs
  • Operating speed (at no load): 0.24 sec/60° at 10V, 0.21sec/60° at 12V, 0.19sec/60° at 12.6V
  • Stall torque (at locked): 150 kg-cm at 10V, 165 kg-cm at 12V, 173 kg-cm at 12.6V
  • Stall current (at locked): 7.4A at 10V, 8.0A at 12V, 8.3A at 12.6V
  • Size: 48 x 30 x 75mm

Experiment 1:

Equipment needed

  • 1.5V D battery: X8
  • 8 D battery holder
  • Jumper cables X4
  • DS51150-180 servo motor
  • Arduino uno
  • Arduino USB cable
Setup

drawing and schematics here...

sketch
                                #include <Servo.h>
                                
                                Servo myservo;  
                                int pos = 0;   
                                
                                void setup() {
                                  myservo.attach(9); 
                                }
                                 
                                void loop() {
                                  for (pos = 0; pos <= 180; pos += 1) { 
                                    myservo.write(pos);              
                                    delay(15);                       
                                  }
                                  for (pos = 180; pos >= 0; pos -= 1) { 
                                    myservo.write(pos);              
                                    delay(15);                       
                                  }
                                }
